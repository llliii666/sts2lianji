# 杀戮尖塔2 联机大厅

一个无注册、三天临时身份、房主手动续期的实时联机大厅 MVP。

## 本地开发

需要 Node.js 24+ 和 npm。

```powershell
npm install
npm run dev
```

默认服务：

- 前端：`http://localhost:5173`
- 后端：`http://localhost:4096`
- 本地数据库：`data/dev.sqlite`

## 验证

```powershell
npm run test
npm run build
```
